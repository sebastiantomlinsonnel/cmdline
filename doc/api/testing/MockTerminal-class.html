MockTerminal

MockTerminal class

A pretend terminal for tests: scripted keys in, captured output out.

Queue up what the "user" types with type, press and line, then run prompts inside run. Everything they draw lands in output, and screen replays it to show what the user would see at the end.

final terminal = MockTerminal()
  ..press(Key.down)
  ..press(Key.enter);
final colour = terminal.run(() => Prompts.menu('Colour', ['Red', 'Blue']));
expect(colour, 'Blue');
expect(terminal.screen.last, contains('Blue'));
