AsciiColourRgb

AsciiColourRgb class

An exact 24-bit ("true colour") colour.

Any of about 16.7 million colours, given as red, green and blue from 0 to 255. Most modern terminals support it. Older ones may round it to the nearest palette colour or ignore it, so use AsciiColour when compatibility matters.

const brand = AsciiColourRgb.hex(0x0B6BCB);
print('${brand.fg}hello$RESET');
