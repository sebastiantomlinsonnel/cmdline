Terminal

Terminal class abstract

The keyboard and screen that prompts and widgets talk to.

Everything interactive reads keys and writes output through Terminal.current, which is the real console by default. Swap it for a fake one (like MockTerminal from package:cmdline/testing.dart) to drive prompts from tests.
