TextBuffer

TextBuffer class

Editable text with a cursor, for text boxes.

Works on user-perceived characters (graphemes), so an emoji or an accented letter is one step of the cursor. Understands the usual editing keys: arrows, Home/End, Backspace/Delete, Ctrl+arrows to jump words, Ctrl+U to clear before the cursor, Ctrl+K after it and Ctrl+W the word before it.
