CliTheme

CliTheme class

The colours and symbols shared by prompts, menus, tables and file helpers.

Everything in lib/src/cli reads CliTheme.current, so swapping it changes the look of the whole toolkit at once:

CliTheme.current = const CliTheme(
  question: AsciiColour(13),
  box: BoxChars.doubleLine,
);

Use paint or say to print styled text, so colour is dropped when the terminal can't show it or the user set NO_COLOR.
