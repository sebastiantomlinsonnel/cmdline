Command

Command class

One thing your program can do, like add in todo add.

A command has its own flags, options and run function. It can also hold more commands inside it, so git remote add style tools are just commands inside commands.

Command(
  name: 'add',
  about: 'Add a task',
  options: [Option('text', short: 't', required: true)],
  run: (input) => print(input.option('text')),
)
