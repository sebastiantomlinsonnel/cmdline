StringRun

StringRun extension

Runs this string as a terminal command, through TerminalCommand.

The command goes to a shell, so pipes, cd and variables all work, and the folder carries over between commands. It runs with env.

When a command fails, a themed error line is printed and a ProcessFailed is thrown, unless you use start with nothrow: true. In verbose mode (Logger.verbose), each command is shown first as a dim ➜ command line.

await 'git pull'.run;
final files = await 'git ls-files'.toList();
final branch = await 'git branch --show-current'.firstLine;
await 'dart test'.forEach((line) => print(line.toUpperCase()));
