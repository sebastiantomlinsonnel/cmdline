Joins style codes and text into one string, with a RESET on each side.

Each item in data can be a code (like BOLD or RED_FG) or plain text. They are joined in order with nothing between them. The leading RESET stops earlier styles from leaking in, and the trailing one stops this style from leaking out.

printCharCodes currently has no effect: both branches add the token unchanged.

print(sty([BOLD, RED_FG, 'Error:', RESET, ' file not found']));

Implementation

String sty(List<String> data, {bool printCharCodes = false}) {
  List<String> temp = [RESET];
  for (final String token in data) {
    printCharCodes ? temp.add(token) : temp.add(token.toString());
  }
  temp.add(RESET);

  return temp.join();
}
