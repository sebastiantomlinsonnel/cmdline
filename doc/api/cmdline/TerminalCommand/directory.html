directory property

String get directory

The folder the next command starts in.

Starts as the folder your app was started in, and changes whenever a command moves somewhere else (with cd, for example).

Implementation

set directory (String path)

Implementation

static set directory(String path) {
  final folder = Directory(path);
  if (!folder.existsSync()) {
    throw ArgumentError.value(path, 'directory', 'The folder does not exist');
  }
  _directory = folder.absolute.path;
}
