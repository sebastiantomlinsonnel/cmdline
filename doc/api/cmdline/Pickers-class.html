Pickers

Pickers class abstract final

Visual pickers for values: sliders, ranges, ratings, dates, files and colours.

They behave like Prompts: live in a terminal, typed answers when input is piped, defaults when unattended, and PromptCancelled on Esc or Ctrl+C.
