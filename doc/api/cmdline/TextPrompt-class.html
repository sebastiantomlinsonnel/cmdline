TextPrompt

TextPrompt<T> class

A one-line text box: free text, passwords and numbers.

Typing edits in place with the usual keys (see TextBuffer). An empty box shows the default dim; Enter takes it and Tab puts it in the box to edit. Enter runs the parser, and a problem shows under the box without closing it.
