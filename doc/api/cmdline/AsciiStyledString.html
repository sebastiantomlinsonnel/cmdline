AsciiStyledString

AsciiStyledString extension

Adds colours and text styles to any String, and chains them together.

Every getter and method returns a new string with the style code at the front and a single RESET at the end. Chaining works because each call removes the previous trailing RESET and slots its code in next to the earlier ones:

print('Done'.bold.foreground(const AsciiColour(10)));
// -> ESC[1m ESC[38;5;10m Done ESC[0m  (without the spaces)

Many styles depend on the terminal; see the matching constants (such as CURLY_UNDERLINE or FRAME) for how widely each is supported.
