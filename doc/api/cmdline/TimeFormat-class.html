TimeFormat

TimeFormat class

A reusable pattern that turns a Moment into text.

Letter runs that match a token (like Do, MMMM, HH) are replaced with the moment's value. Everything else is kept exactly as written. Wrap text in [brackets] to stop it being read as a token, e.g. '[a] h:mm'.

final f = TimeFormat('The $Do of $mmmm $yyyy at $HH:$mm:$ss');
f.format(Moment.now()); // → "The 8th of November 2026 at 14:35:09"
