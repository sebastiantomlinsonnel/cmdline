ProgressBar

ProgressBar class

A progress bar that fills up on one line of the terminal.

Tell it how many steps there are, move it along with add or update, and end it with done or failed, which leave a PASS or FAIL line.

final bar = ProgressBar('Copying files', total: files.length);
for (final file in files) {
  await copy(file);
  bar.add();
}
bar.done('Copied ${files.length} files');

Shows as: LOG | Copying files ██████████▍ 52% 13/25

Don't print anything else while the bar is showing, or it will be split over two lines.
