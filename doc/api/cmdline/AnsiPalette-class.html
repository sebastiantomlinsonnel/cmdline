AnsiPalette

AnsiPalette class abstract final

The shared colours for the package's look.

Soft, slightly muted pastels that read well on dark terminals. The first group is what Logger.getVerbosityColour uses for each Level; the second group is extra colours in the same style for anything else.

print('done'.foreground(AnsiPalette.sky).bold);
