Spinner

Spinner class

An animated spinner with a label, for work of unknown length.

Start it, let the work run, then end it with pass, fail or stop. It shows how long the work has taken. Use log to print lines above the spinner while it runs. When output is piped, nothing animates and only the final line is printed.

final spinner = Spinner('Installing packages').start();
try {
  await install();
  spinner.pass('Installed 12 packages');
} catch (e) {
  spinner.fail('Install failed: $e');
}

// Or let it handle the ending:
final data = await Spinner.run('Downloading', () => fetch(url));
