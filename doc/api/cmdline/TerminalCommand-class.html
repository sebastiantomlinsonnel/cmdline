TerminalCommand

TerminalCommand class

Runs commands as if you typed them into a terminal.

The command goes to a shell (PowerShell on Windows by default), so you can use anything you would type yourself: pipes, variables, cd, cmdlets and so on. What it prints shows up in your terminal as it happens, and you also get it back to read.

The folder is remembered between commands, just like a terminal window, so a cd carries over to the next command:

await TerminalCommand.run('cd ~');
await TerminalCommand.run('dir');              // Lists your home folder.
await TerminalCommand.run(r'Get-Content $PROFILE');

final result = await TerminalCommand.run('git status', show: false);
if (result.ok) print(result.lines);

await TerminalCommand.run('dir /b', shell: TerminalShell.cmd);

Variables you set (like $env:NAME = 'x') only last for that one command, since each command gets a fresh shell.
