Strings

Strings class

Null-safe String utilities that extend the core String API.

A Strings method never throws on a null argument. A null String is treated as an empty String, or as a space-filled String where a range is requested, so the caller gets a result of the expected length.

Strings.substring(null, 2, 3);
// -> ' '
