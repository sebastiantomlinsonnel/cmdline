Parser

Parser class cli

Reads the user's arguments one word at a time.

Make a new Parser for each list of arguments and call parse. Most code never uses this directly, because CLI.start does it for you.

It understands:

  • flags: --urgent, -u (one lowercase letter), and --no-urgent for negatable flags
  • options: -text Buy, -text=Buy, -T Buy (one capital letter)
  • command names (and aliases), which switch to that command
  • --, after which every word goes into Input.rest
  • --help, -h, help <command> and --version
