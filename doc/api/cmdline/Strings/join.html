Joins the elements of list with separator.

A null list returns an empty String. Null elements are treated as empty strings but still get a separator. If excludeEmpty is true, null and blank String elements are left out.

Strings.join(null);                  // ''
Strings.join([1, 2]);                // '12'
Strings.join([1, 2], separator: ','); // '1,2'

Implementation

static String join(
  List<Object?>? list, {
  String separator = '',
  bool excludeEmpty = false,
}) {
  if (list == null) {
    return '';
  }

  if (excludeEmpty) {
    return list
        .where(
          (element) =>
              element != null &&
              (element is! String || Strings.isNotBlank(element)),
        )
        .join(separator);
  }
  return list.map((element) => element ?? '').join(separator);
}
