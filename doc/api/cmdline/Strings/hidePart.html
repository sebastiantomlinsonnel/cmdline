Masks the characters of string from start up to, not including, end.

start defaults to 0 and end to the end of the string. Positions count user-perceived characters. Each hidden character is replaced with replaceWith, which defaults to '*'. Returns an empty string for null.

Implementation

static String hidePart(
  String? string, {
  int start = 0,
  int? end,
  String replaceWith = '*',
}) {
  if (string == null) {
    return '';
  }
  end ??= string.length;

  final sb = StringBuffer();
  var pos = 0;
  for (final ch in graphemes(string)) {
    sb.write(pos >= start && pos < end ? replaceWith : ch);
    pos++;
  }
  return sb.toString();
}
