PromptView

PromptView<T> class abstract

The base of every interactive prompt.

A prompt draws itself as text lines, reacts to key presses and, once done, gives back its result. PromptRunner does the rest: raw mode, redrawing, the question line, errors, key hints and the line and unattended fallbacks.

To make your own, extend this and fill in the parts that matter:

class Counter extends PromptView<int> {
  int count = 0;
  Counter() : super('Count');

  @override
  String inline() => '$count'.bold;

  @override
  KeyResult onKey(KeyPress press) => switch (press.key) {
    Key.up => (count++, KeyResult.handled).$2,
    Key.enter => KeyResult.done,
    _ => KeyResult.ignored,
  };

  @override
  int get result => count;
}

final n = PromptRunner.run(Counter());
