Option

Option class

A named setting that takes a value, like --name Sam or -n Sam.

Give it to a Command or CLI in their options list, then read it in run with input.option('name'), or input.options('name') when multiple is on.

Options always use one dash, so the user can type the value in any of these ways: -name Sam, -name=Sam or -N Sam.

Option('priority', short: 'P', allowed: ['low', 'high'], defaultValue: 'low')
