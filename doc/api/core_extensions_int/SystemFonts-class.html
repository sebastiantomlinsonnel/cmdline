SystemFonts

SystemFonts class

Singleton that discovers and indexes system fonts at runtime.

SystemFonts scans the platform's standard font directories (Windows, Android, macOS, Linux) for .ttf and .otf files. In Flutter, the recollect package adds loadFont, loadAllFonts and loadFontFromPath so you can load them into Flutter's font engine on the fly — no need to bundle every font in your asset manifest.

On Android the system font directories are read-only and hold only the families the ROM ships (Roboto, Noto and friends), so expect a much shorter list there than on desktop.

Getting Started

final fonts = SystemFonts();

// See what's available
final allFonts = fonts.getFontList(); // ['Arial', 'Courier New', ...]

// Load one font for use in TextStyle (Flutter only)
await fonts.loadFont('Fira Code');

// Or load everything at once
await fonts.loadAllFonts();

Custom Font Directories

If your fonts live somewhere non-standard, point the scanner there:

fonts.addAdditionalFontDirectory('/opt/my-fonts/');

How It Works

  1. On first access, the constructor scans platform-specific directories.
  2. getFontPaths lazily collects all .ttf/.otf file paths.
  3. getFontMap builds a {name: path} lookup from those paths.
  4. In Flutter, loadFont reads the bytes and registers them with FontLoader. Loaded fonts are cached, so loading the same name twice is a no-op the second time.
