Double extension

Helpful extensions on nullable double values.

These make it painless to work with doubles that might be null — you get safe defaults, range checks, and quick conversions without scattering null-checks throughout your code.

double? maybeValue;
print(maybeValue.validate()); // 0.0 (safe default)
